## Pop！

首先用 Template String 确定 DOM 具体如何，然后再 JQAppend 插入到网页中。由于我需要弹出多个窗口，每一个窗口不能够都在中间堆着，所以需要施加偏移。同样以 X 坐标为例，Y 坐标同理。首先用随机数产生一个 currentX 作为初始坐标，在 DOM 进入文档流后施加 translateX3d，然后将 X 坐标从中间移动过去即可。

## Drag!

在这里我不得不承认 DS 对于拖动的 EventListener 的鲁棒性设计更讲究，即**当标题栏按下的时候，才需要监听鼠标移动和鼠标弹起的事件，同时当鼠标弹起，自动结束鼠标移动和弹起的 EventListener 的生命周期**。

关于移动，和掘金的文章差别并不大。mousedown 记录移动的初始位置 start 和经过前序移动后的初始变换位置 base 并且设置为正在拖拽，mousemove 在“正在拖拽”时更新当前位置 current，mouseup 结束两个 Eventlistener 的生命周期，并把窗口设置为不在拖拽。

## Top!

在这里我想说一下原网页的一个缺陷，也就是“点击窗口时窗口不会置顶”的问题。要解决这个问题实际上很容易，只需要监听点击事件，让 `.pout` 的 `z-index` 足够大即可。
