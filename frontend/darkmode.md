# 分析

暗黑模式，究其本质就是将另一套颜色主题样式应用到页面中。为了解决暗黑模式的问题，我们需要确定：

- 设计上，这套主题样式应该长什么样子？
- 实现上，如何应用？

实现上，根据我的初步想法，有以下方案：

1. 通过滤镜，让部分元素反相（但是看上去很丑）
2. 维护一个新的样式表，样式表中有不同类名的设计，在切换时动态替换每一个元素的类名（对于元素过多的情况，这样不现实）
3. 维护一个新的样式表，样式表中指定不同颜色主题的配色，然后在切换时只重新声明主题

显然第三个方案更有可行性，具体的实现方案可以参考 [Deepseek](https://chat.deepseek.com/share/xx8t6fmbzz2d2tihyp)。我们在此选择使用 `light-dark()` 做具体的实现。

另外题目要求内容也需要更换，因此我们还需要找一些适合于暗色模式的图片。由于题目的案例是 Unsplash 之中的，那我们也选择这个吧。

## 1.2
通过给元素的颜色加上 `light-dark()` 进行配置。但是发现很多颜色都可以复用，因此更简单的方式是声明几个变量，变量在声明的时候就用 `light-dark()`，后面如果需要调整就只需要调整变量的内容了。

我采用的是 [扁平化设计配色](https://htmlcolorcodes.com/zh/yanse-biao/bianping-hua-sheji-yanse-biao/)，这个网站提供的 HEX 色码和透明是不兼容的。为了解决这个问题，采用了 `color-mix()`，将颜色和透明进行混合得到了类似 RGBA 的效果。

另外样式真的很迷，为什么有一些是在 head 里面规定的样式，一些又是在 body 里面元素里面规定的样式？这个问题暂时不解决，但是对 input 确实有影响，因此删除了 input 的部分样式，而在前面的样式表中规定了颜色。

浅色的那个渐变有点丑，换了个更亮的形式。（我改了也丑……）

## 1.3
图片替换的话会比普通的暗黑模式更麻烦一些。如果是那个背景，可以直接使用 `light-dark()`，但是还有那些景点的风景图不能够直接替换，有多个方案：

1. 把 img 换成 div，div 设置背景图片就可以 `light-dark()` 一步到位了
2. 使用 JS 做 url 替换
3. 添加多个 img，指定对应的 class 只在部分视图启用

我想题目的本意应该是让我采取最后一种方法，所以最后使用该方法实现。
